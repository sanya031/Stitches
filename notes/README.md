# Notes

`claude-memory/` — the working rules Claude Code kept for this project (one rule per file, `MEMORY.md` is the index).
On a new machine, copy them into Claude Code's memory folder for this project so they apply again:

    ~/.claude/projects/<project path with / as ->/memory/

e.g. for a checkout at ~/Downloads/stitches: `~/.claude/projects/-Users-<you>-Downloads-stitches/memory/`.

Run locally: `npx serve .` (or `python3 -m http.server 5179`), then open /studio/.
